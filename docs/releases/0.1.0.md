# AI Usage 0.1.0

The first public release of AI Usage:

- Claude Code and Codex limits in one native macOS menu bar panel
- Provider-specific monochrome menu bar icons
- Compact Liquid Glass design for light and dark mode
- Five-minute background refresh and one-click manual refresh
- Launch at Login
- Daily, EdDSA-signed over-the-air update checks powered by Sparkle

AI Usage reads the local sessions already created by Claude Code and Codex. It
does not require another account or API key, and it does not collect telemetry.

This first build is ad-hoc signed because a Developer ID certificate is not
available yet. macOS may ask you to confirm it once by right-clicking the app
and choosing **Open**.
