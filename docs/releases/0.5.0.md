# AI Usage 0.5.0

This release shows when a session will run out early, and fixes Antigravity
and Cursor.

- Show when a session is on pace to run out before it resets. Its card reads
  "Out 57m" beside the reset time, and an hourglass marks it there and in the
  menu bar. The estimate comes from the current reading, so nothing is stored,
  and weekly and monthly limits don't get one.
- Fix Antigravity showing 100% left while Antigravity itself showed usage.
  AI Usage now reads the Google host that counts Antigravity's usage, and
  Argon Weekly appears on accounts where it was missing.
- Stop reporting an expired Cursor session on Cursor 3.27 and later, which
  encrypt the editor's login. AI Usage uses the Cursor CLI's login instead:
  install the Cursor CLI and run `agent login` once.
- Say when a Claude organization doesn't allow OAuth sign-ins, instead of
  asking you to log in again.
