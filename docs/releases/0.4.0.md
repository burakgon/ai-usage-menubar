# AI Usage 0.4.0

This release adds Kiro and lets you put your providers in your own order.

- Add Kiro's monthly credits, free-trial credits, and overage spend, using the
  sign-in Kiro or `kiro-cli` already has, or `KIRO_API_KEY`.
- Drag the handle beside each provider in Settings to reorder them. The usage
  panel and the menu bar follow the same order. With VoiceOver, use the Move Up
  and Move Down actions.

Thanks to whale9820 and abdullayevilkin for these contributions.
