# AI Usage 0.1.5

This release fixes missing menu bar values for pinned providers.

- Prefer the Session or Weekly period selected in Settings whenever that
  period is available.
- Fall back to the provider's other primary period instead of showing `--`
  when Claude Code or Codex only returns one primary quota window.
- Keep Automatic mode scoped to the selected period so comparisons remain
  consistent across providers.
- Never substitute Spark-specific quotas for the main Codex quota.

Thanks to [@cneren](https://github.com/cneren) for the contribution.
