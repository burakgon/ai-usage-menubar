# AI Usage 0.3.2

This release keeps your other sign-ins intact when AI Usage renews a login.

- Keep Claude Code's MCP server logins when AI Usage renews your Claude login.
  Earlier versions dropped them, so Claude Code asked you to sign in to each
  MCP server again.
- Keep the rest of Grok's sign-in file when AI Usage renews its token, and
  leave a login Grok renewed in the meantime untouched. Grok's rate limits now
  show as rate limits.
- Stop reporting an expired Antigravity session when Google only declines to
  share the plan. AI Usage now asks both Google hosts before treating a token
  as refused.
- Keep the Update button's label readable on its blue glass.

Thanks to straki and whale9820 for these fixes.
