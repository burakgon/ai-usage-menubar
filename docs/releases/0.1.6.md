# AI Usage 0.1.6

This release eliminates sustained CPU usage while the menu bar panel is closed.

- Replace the permanently hosted SwiftUI menu bar window with a native AppKit
  status item.
- Create the Liquid Glass dashboard only when it is opened, then release its
  complete SwiftUI hosting tree when the panel closes.
- Keep menu bar percentages, monochrome provider icons, stale-state warnings,
  accessibility labels, and saved preferences unchanged.
- Preserve the existing compact panel design in light mode, dark mode, and
  Reduce Transparency.

The result is a lighter idle app without changing Claude Code, Codex, refresh,
launch-at-login, or signed update behavior.
