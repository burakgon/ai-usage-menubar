# AI Usage 0.3.1

This release keeps the providers AI Usage starts tracking after an update.

- Remember newly supported providers after a relaunch. Since 0.2.0, Cursor,
  Antigravity, GitHub Copilot, Devin, and Grok could stop being tracked the
  next time AI Usage opened, and 0.3.0 did the same to Z.ai.
- Track them again once on installations where they were dropped. A provider
  you turn off in Settings stays off.
