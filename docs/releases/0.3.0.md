# AI Usage 0.3.0

This release brings every provider up to date and adds Z.ai.

- Show banked Claude Code and Codex usage-limit resets, when each one expires,
  and an orange warning in the day before the next one expires.
- Add Z.ai GLM Coding Plan session, weekly, and web search limits, using the
  key Claude Code or OpenCode is already set up with.
- Restore Antigravity's Gemini limits and plan, add the Argon weekly quota, and
  read a running Antigravity app or `agy` CLI when Google withholds an
  account's quota instead of reporting it as signed out.
- Show Claude Code's weekly usage in the menu bar on accounts without a session
  window.
- Use current plan names: Claude Max and Ultra, and Codex Pro 100, 200, and 500.
- Show Claude Code extra usage in your billing currency and Cursor on-demand
  spend, and hide Codex credits on accounts without them.
- Show fully used Devin quotas, explain Grok team accounts, and treat GitHub's
  rate limits as rate limits instead of expired sign-ins.
- Wait progressively longer after repeated Claude rate limits.
- Use the official Copilot, Devin, and Grok marks, and keep provider cards
  inside the panel while scrolling.
