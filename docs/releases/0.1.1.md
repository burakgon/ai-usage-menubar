# AI Usage 0.1.1

This release fixes startup for the current ad-hoc signed distribution.

Sparkle's embedded framework has its own code signature. Hardened Runtime
library validation rejected that framework when the host app had only an
ad-hoc signature, causing version 0.1.0 to exit before showing its menu bar
item. Version 0.1.1 disables Hardened Runtime only for the unsigned fallback
build. Developer ID signed releases continue to use Hardened Runtime and can
be notarized normally.

All Claude Code, Codex, Liquid Glass, Launch at Login, and signed OTA features
from 0.1.0 are unchanged.
